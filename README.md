# JoinUp  
**Rutgers Capstone Project**

JoinUp is a full-stack web platform built to help students and early-career creators connect, collaborate, and gain real-world project experience. Users can post projects, apply to roles, and network with peers across universities based on skills and interests.

---

## Problem
Students and recent graduates often struggle to find meaningful collaboration opportunities that provide hands-on experience. Networking platforms are often overwhelming or lack a clear focus on skill-based project collaboration.

---

## Solution
JoinUp provides a centralized platform where students can:
- Find and join collaborative projects
- Build profiles highlighting skills and university affiliation
- Apply to project roles and pitch themselves
- Gain experience working in real, cross-functional teams

---

## Features
- Passwordless user authentication
- Student profiles with school affiliation
- Project posting and role-based applications
- Profile editing and personal pitching
- Project filtering for accessibility
